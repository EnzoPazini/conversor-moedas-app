# Conversor de Moedas (App)

Aplicativo mobile para converter valores entre diferentes moedas, feito com React Native e Expo.

> 🚧 Em desenvolvimento: a tela inicial e o componente de botão estão estruturados; a lógica de conversão ainda será implementada.

## Tecnologias

- React Native 0.81
- Expo SDK 54

## Como rodar

```bash
npm install
npx expo start
```

Escaneie o QR code com o app **Expo Go** (Android/iOS) ou pressione `w` para abrir no navegador.
